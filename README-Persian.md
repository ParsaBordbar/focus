- به‌صورت خودکار از وب‌سایت‌های حواس‌پرت‌کن (مثل TikTok، Instagram، Shorts) ریدایرکت می‌کنه

- امکان فعال‌/غیرفعال‌سازی سریع از طریق پاپ‌آپ  
- **حالت No AI** – مسدود کردن چت‌بات‌های هوش مصنوعی (ChatGPT، Claude، Gemini، Copilot و …) تا خودتان فکر کنید  
- **جلسه‌های زمان‌دار** (اختیاری) – برای جلسه اسم بگذارید، مدتش را تعیین کنید و تا تمام شدن زمان، Focus قفل می‌ماند  
- **صفحه تنظیمات** – روشن/خاموش کردن حالت‌ها و مدیریت سایت‌های مسدود و منابع مفید  
- طراحی ساده، سبک، و بدون استفاده از فریم‌ورک – بدون مزاحمت برای روند کاری شما

## 🔧 نصب افزونه

1. این مخزن را کلون یا دانلود کنید:

   ```bash
   git clone https://github.com/your-username/focus-extension.git
   ```
مرورگر Chrome را باز کنید و به آدرس زیر بروید:

```
chrome://extensions/
```
حالت توسعه‌دهنده (Developer mode) را در گوشه بالا سمت راست فعال کنید

روی گزینه "Load unpacked" کلیک کرده و پوشه‌ای که مخزن را در آن کلون کرده‌اید انتخاب کنید

کار تمام است! آیکن افزونه Focus را در نوار افزونه‌ها مشاهده خواهید کرد

🔘 فعال یا غیرفعال کردن افزونه

روی آیکن Focus در نوار افزونه‌ها کلیک کنید و با استفاده از سوییچ، محافظت را روشن یا خاموش کنید.

⚙️ تنظیمات

روی آیکن چرخ‌دنده در پاپ‌آپ کلیک کنید (یا روی آیکن Focus راست‌کلیک کرده و Options را بزنید). در صفحه تنظیمات می‌توانید:

- حالت‌های Focus، No AI و Clean YouTube را روشن یا خاموش کنید
- سایت‌های مسدود دلخواه را خط به خط اضافه کنید: دامنه (`reddit.com`)، دامنه + مسیر (`discord.com/channels`) یا یک کلمه برای مسدود کردن هر دامنه‌ای که آن را دارد
- منابع مفید خودتان را اضافه کنید (جایگزین لیست پیش‌فرض می‌شوند)

⏱️ جلسه‌های زمان‌دار

به‌صورت پیش‌فرض خاموش است. در تنظیمات **Timed sessions** را روشن کنید و مدت جلسه را به دقیقه (۱ تا ۲۴۰) بنویسید. بعد:

- زیر دایره در پاپ‌آپ برای جلسه اسم بگذارید (اختیاری؛ آخرین اسم یادش می‌ماند)
- روی دایره بزنید: Focus روشن و تایمر شروع می‌شود. حلقه‌ی دور دایره پر می‌شود و آیکن افزونه دقیقه‌های باقی‌مانده را نشان می‌دهد
- تا پایان جلسه Focus قفل است. برای پایان زودتر، **دایره را ۵ ثانیه نگه دارید**
- وقتی زمان تمام شود، Focus خاموش می‌شود و نوتیفیکیشن می‌گیرید. جلسه‌های تمام‌شده با اسمشان در تنظیمات نمایش داده می‌شوند

🤖 حالت No AI

از صفحه تنظیمات روشنش کنید. وقتی Focus روشن است، چت‌بات‌های هوش مصنوعی هم مسدود می‌شوند:
ChatGPT، Claude، Gemini، AI Studio، NotebookLM، Copilot، Perplexity، DeepSeek، Grok، Meta AI، Mistral، Poe، Character.AI، HuggingChat، Phind، You.com، Pi، Kimi و Qwen.

🔄 شخصی‌سازی سایت‌ها

می‌توانید لیست سایت‌های حواس‌پرت‌کن و منابع مفید را از طریق بوک‌مارک‌های Chrome تنظیم کنید:

وارد آدرس زیر شوید:

```
chrome://bookmarks/
```
دو پوشه‌ی جدید ایجاد کنید:

Dopamine Sites → برای وب‌سایت‌هایی که می‌خواهید از آن‌ها دوری کنید

Good Sources → برای وب‌سایت‌هایی که می‌خواهید به آن‌ها ریدایرکت شوید

لینک‌های دلخواه خود را به این پوشه‌ها اضافه کنید. به‌عنوان مثال:

Dopamine Sites:

https://www.reddit.com

https://twitter.com

Good Sources:

https://wikipedia.org

https://github.com

افزونه به صورت خودکار این پوشه‌ها را خوانده و منطق مسدودسازی/ریدایرکت رو به‌روزرسانی می‌کنه.
